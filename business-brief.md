# Business Brief

This file is the **input** to the Revenue Operating System. Everything else in
this project (the four agents, the runbook) stays the same every time you run
it — this is the only file you edit when you want to run the system on a new
idea.

Fill in every section below before starting a run. Short, honest answers are
better than polished ones — the agents will do the polishing.

When you start a new run for a **different** idea, don't overwrite this file
blindly if you might want to revisit the old idea later — save a copy first
(e.g. `outputs/<old-run-slug>/business-brief.md`) or keep multiple brief
files and tell the coordinator which one to use for that run.
