# Execution

This folder is different from `outputs/`. `outputs/<run-slug>/` holds the
**strategy** produced by the Revenue Operating System (research, offer,
content, conversion design) — that work is finished and approved, and
those files don't change during day-to-day business operation.

`execution/<run-slug>/` holds the **operational tools** you actually use
day-to-day to run the business the strategy describes — prospecting
templates, trackers, and similar working documents. These get filled in
and updated constantly as you work; the strategy files never do.

Keeping them separate means you can always tell "what we decided" (outputs)
apart from "what we're doing right now" (execution).
